# Web UI（スタジオ・筆跡）

1 つのサーバーで 2 つの画面を配る。

- **スタジオ** `/`（PC）: 原稿を書く → 清書する → プロッタで描く。
- **筆跡** `/collect`（iPad＋Apple Pencil）: 筆跡を集める → 見直す → 学習させる。

プロッタへの送信はブラウザの WebSerial で行い、旧 Tkinter GUI は WebSerial が使えない環境向けの予備。

## 起動

```sh
python scripts/run_ui.py --checkpoint data/models/finetuned.pt   # make ui でも可
```

プロッタをつないだ PC の **Chrome / Edge** で `http://localhost:7860` を開く（`--open` で自動で開く）。
iPad では同じ LAN から `http://<PC の IP>:7860/collect` を開く（`make collect` / `scripts/collect_strokes.py` は
この画面を開いて起動するだけ。旧ポート 8080 の収集サーバーは廃止）。

| オプション | 既定 | 意味 |
|---|---|---|
| `--checkpoint` | なし | 起動時に清書に使う ML モデル |
| `--models-dir` | `data/models` | 選べるモデルと、学習の保存先（この外へは書かない） |
| `--user-strokes-dir` | `data/user_strokes` | 筆跡（プロファイルのルート）。無ければ作る |

- WebSerial は Secure Context（`localhost` か https）でしか使えない。LAN の別 PC から
  `http://192.168.x.x:7860` で開いた場合は、清書と G-code の保存まではできるが送信はできない。
- Firefox / Safari は WebSerial 非対応。
- CH340 USB-Serial ドライバを Windows に入れておく。

## 画面

| 場所 | 役割 |
|---|---|
| 左「原稿」 | 本文を書く。見出し・数式・表は色分けされる。「例文」「書式」（クリックで挿入）。原稿はブラウザに自動保存 |
| 中央「用紙」 | 入力に合わせて組版の**下書き**（水色）がすぐ出る。「清書する」で手書きストロークがペン順に描かれる。ドラッグで移動、⌘/Ctrl＋ホイールで拡大 |
| 右「仕上がり」 | 筆跡プロファイル・雰囲気プリセット（端正〜走り書き）・各スライダー。字形の出どころ（あなたの筆跡 / ML / KanjiVG / 幾何 / 未収録） |
| 右「プロッタ」 | 接続・原点復帰・ペン上下・描くページの選択・開始 / 一時停止 / 停止 / 緊急停止・通信ログ |

上部の「1 書く → 2 清書 → 3 描く」が今どこまで進んだかを示す（クリックでその操作へ）。

## 筆跡（/collect）

上部で「書き手」（プロファイル）を選ぶ。選択はスタジオと共有され、端末ごとに別の人を選べる。

### 集める

- 右のマスに Apple Pencil で書き、「保存して次へ」（Enter）。書いた字が左の点へ吸い込まれて 1 つ埋まる。
  直後のトーストの「取り消す」で保存を取り消せる。
- 左にはお手本（KanjiVG）の書き順が 1 画ずつ動く。タップでもう一度。「お手本を敷く」でマスに薄く敷ける
  （癖が消えやすいので既定は off）。
- 画数がお手本と違うと下のラベルが黄色になる（保存は止めない）。
- ペンを検出すると指・手のひらでは書けない。**二本指タップで 1 画戻す**。ペンが無い端末は「指でも書く」。
- 収集順は「レポート頻出 → 基本 → 標準」、同じ段では少ない字から。1 字は 1 回ずつ書いて次の字へ進む。
- スタジオで清書したあと「筆跡画面で書いて教える」を押すと、自分の筆跡が無かった字が **依頼** として届く。
  「この字から書く」でその字だけを順に書ける（保存すると依頼から消える）。

### 見直す

- 収集セットの全字をマスで並べる（下の 3 本線がサンプル数、赤い点が要確認）。「まだ / そろった / 要確認」で絞り込み。
- 字を選ぶと、**清書ではどう書かれるか**（スタジオと同じ経路で 3 通り）と、あなたのサンプルが並ぶ。
  サンプルは 1 つずつ、または全部消せる。消したものは `<root>/.trash/` に移るだけで、トーストの「元に戻す」で戻る。
- 「要確認」は形があやしいサンプル（点が少ない・小さい・速すぎる 等）と、画数がそろっていない字。「問題ない」で以後出さない。

### 学習

- 「はじめから」（ユーザーデータ学習）か「微調整」（元モデルから）を選び「学習を始める」。データは「この人だけ / 全員」。
- エポック・損失の推移・ログが出る。終わったら「このモデルを使う」で、**再起動せずに** スタジオの清書に反映される。
  モデルは右の一覧、またはスタジオの「清書のモデル」でも切り替えられる。
- 保存先は `--models-dir` 配下だけ（LAN に公開しても外へ書けない）。CPU だと 1 エポックに数分かかる。

## 清書と G-code は同じもの

清書（`POST /api/render`）は 1 回の生成でプレビュー用のストロークと G-code を**同じストロークから**作る。
画面で見た字形がそのまま紙に描かれる。「書きぶり番号」（seed）が同じなら何度清書しても同じ字形になり、
「書き直す」で別の番号を引く。設定や原稿を変えると清書は「古い」表示になり、下書きが重なる。

## 描く

1. 「プロッタで描く」（未接続なら「接続して描く」）→ ポート選択で CH340 を選ぶ。
   一度許可したポートは次回から「再接続する」で選択なしにつながる。一覧に出ないときは「すべてのポートから選ぶ」。
2. 用紙を左上の角に合わせて置き、「描画を開始」。各ページの G-code 先頭で原点復帰（`$H` → `G92 X0 Y297 Z0`）する。
3. 用紙上で未描画の線は薄く、描いた線は濃く、ペン先は朱の十字で示す。残り時間は実測で補正される。
4. 複数ページは 1 ページごとに「用紙を交換してください」で止まる。交換して「続ける」（Enter）。
5. ほかの G-code を描くときは「G-code を開く」（`.gcode` / `.nc` / `.txt`、複数可＝ページ扱い）。

| 操作 | 動き |
|---|---|
| 一時停止（Space / Esc） | **次にペンを上げた直後**で止まる（紙にペンを押し付けたまま止めない） |
| 停止 | 次の行の前で止め、ペンを上げる |
| 緊急停止 | GRBL realtime `!` と soft reset `0x18` を即送信。位置を失うので再開前に原点復帰 |

## 安全仕様

- 115200bps。1 行送って `ok` を待つ（stop-and-wait）。`error:*` / `ALARM:*` / 応答タイムアウトで中止しログに出す。
- ペン上 `G1G90 Z0.5 F5000`、ペン下 `G1G90 Z5.0 F5000`（`PlotterConfig` と同じ）。
- 空行・`;` コメント・括弧コメントは送らない。
- 描画中は接続・切断・原点復帰・ペン操作をロックし、ページを閉じようとすると確認が出る。
- USB が抜けたら即座に未接続へ戻る。

## 実機チェック

- [ ] Chrome / Edge の `http://localhost:7860` で「接続する」が押せる。
- [ ] 接続ダイアログに CH340 が出る（出なければ「すべてのポートから選ぶ」）。
- [ ] 原点復帰後、紙座標が `(0,0)=左下`, `(210,297)=右上` になる。
- [ ] ペン上 / ペン下が Z 軸で動く。
- [ ] 清書した原稿を描ける。用紙上の進捗が実機のペン位置と一致する。
- [ ] 一時停止でペンが上がった状態で止まり、再開で続きから描く。
- [ ] 2 ページ以上で用紙交換の案内が出て、続けると 2 ページ目を描く。
- [ ] 停止でペンが上がる。緊急停止で物理動作が止まり、原点復帰後に再開できる。
- [ ] `error:*` / `ALARM:*` を返す行で止まり、ログに内容が出る。

## 開発（画面のつくり）

- 画面は Preact + htm。ライブラリは `src/ui/static/vendor/` に同梱し、各 HTML の import map で読むのでビルドも npm も要らない（更新手順は `vendor/README.md`）。
- 画面ごとに `state.js`（状態と操作。`store.js` のストア）と `view.js`（状態を読んで描くだけ）に分ける。
  用紙ビューア・プロッタ・エディタ・書き込みパッドのような命令的な部品は state.js が持ち、Preact が作った要素に結び付ける（Preact には描き直させない）。
- 画面テスト: `uv sync --extra e2e` → `uv run playwright install chromium` → `pytest -m e2e`。
  プロッタはブラウザ内の偽シリアルに置き換えて、清書 → 2 ページ送信（一時停止・用紙交換・停止）、筆跡の保存・取り消し・見直し・依頼・モデル切り替えまで通す。
