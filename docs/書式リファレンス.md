# 入力書式リファレンス

Web UI（Gradio）のテキスト欄に入力する本文の書き方まとめ。
Markdown 風の記法で、見出し・数式・表などを手書き風に組版する。

実装: `src/layout/typesetter.py`（`typeset()` が第1パスで段落解析 → 各ブロックを配置）。

---

## 見出し

行頭に `#` を付ける。最大3段階で、階層ごとに左インデントが深くなる。

```
# 大見出し
## 中見出し
### 小見出し
```

- フォントは見出しレベルで拡大（1.15 / 1.08 / 1.0 倍）。
- 見出し直後の本文も同じインデント階層に揃う。

## 段落

- **空行**で段落を区切る。
- 段落内は本文幅で自動折り返し（禁則処理あり）。
- 段落冒頭に `\noindent 本文` と書くと、その段落の先頭行を字下げしない。

## 数式

### 基本

| 種類 | 書き方 | 説明 |
|---|---|---|
| インライン | `$V = IR$` | 文中に埋め込む |
| ブロック | `$$E = mc^2$$` | 独立行に中央配置。`\\` で複数段 |
| 分数 | `$\frac{a}{b}$` | 分子/分母を上下に。**ブロック内は `\dfrac` 推奨**（本文サイズを維持） |
| 平方根 | `$\sqrt{2gh}$` | 根号記号は幾何描画（手書き風）。`\sqrt{\frac{a}{b}}` の入れ子OK |
| 上付き | `$x^2$` `$x^{10}$` | 1文字ブレースなし、複数はブレース |
| 下付き | `$p_1$` `$v_m$` | 同上 |
| ギリシャ | `$\alpha$` `$\beta$` `$\omega$` `$\Delta$` `$\sigma$` `$\rho$` `$\nu$` `$\lambda$` `$\pi$` `$\mu$` | 主要文字対応。Unicode 直書き（`Δ σ ν` 等）も OK |
| 演算子 | `\cos \sin \tan \log \exp \sum \int \cdot` | LaTeX 記法 |
| 式番号 | `$$ E=mc^2 \tag{1}$$` | ブロック数式の右端に `(1)` を併置 |

### 挙動メモ

- **単純式は本文書体に自動統一**: `$V=IR$` `$P$` `$\sigma$` のように sub/sup/frac/sqrt を含まない式は matplotlib(Computer Modern)でなく本文と同じ手書き経路で描画される。書体が浮かない
- **分数線を罫線に揃える**: ブロック数式でトップレベル分数（式の一番外側が `\frac`）は分子が上の罫線行・分母が下の罫線行に分かれ、分数線が境界の罫線に乗る
- **`\dfrac`**: 分数の中に分数を入れると `\frac` は subsize が累積して文字がどんどん小さくなる。ブロック数式では `\dfrac{}{}` を使うと本文サイズを維持
- **長い式**: 幅が本文幅を超えると自動縮小して収める。`\\` で改行して2段にする方が読みやすい
- **数式内の `.`** は小数点として保持（本文の `.` は句点 `。` に自動変換される）

## 表（Markdown パイプ表）

```
| 材料 | 降伏応力 | 引張強さ |
|---|---|---|
| SS400 | 245 | 400 |
| S35C | 305 | 510 |
: 表1 各材料の機械的性質
```

- **2行目の区切り行 `|---|---|` が必須**（これが無いとただの本文扱い）。
- 列幅は各列の最大文字数から自動決定し、本文幅を超える場合は縮小して収める。
- 表は**本文幅の中央**に配置。横罫線は用紙の罫線に揃う。
- **キャプション**: 表の直後に `: タイトル` の行を書くと、表の真下に中央寄せで描画（Pandoc 式）。省略可。
  - 学術慣例では表のタイトルは上が標準だが、本ツールは下配置。

## 句読点・記号

- 本文の半角ピリオド `.` は句点 `。` に自動変換（数式内は除く）。
- 幾何描画対応記号: `、。・（）「」『』` と ASCII 数式記号 `+ - = < > * / % : ; ! ?`
- 数字(0-9)・英字は専用字形で描画（ML 変形を通さないので崩れない）。

## 対応文字

ひらがな・カタカナ・漢字（常用）・英数字・数式記号。
手書きサンプル収集済みの文字はユーザー筆跡、それ以外は KanjiVG ベースで生成。
プレビュー後「文字カバレッジ」で各文字の描画方式を確認できる。

## 手書きらしさ・実機の設定（スライダー）

書式ではないが、設定パネルで調整できる主な軸。詳細は CLAUDE.md 参照。

| スライダー | 既定 | 効果 | 実機メモ |
|---|---|---|---|
| `temperature` | 0.2 | 字形そのものの揺らぎ（ML per-point offset） | — |
| `messiness` | 0.4 | 行内の上下動・字間・サイズ・傾き | — |
| `instance_variation` | 0.1 | 同じ字を毎回少し変える | — |
| `pressure_variation` | 0.0 | 画内の濃淡 | 実機は描画中Zが振れ点線化するため0推奨（プレビュー演出用） |
| `entry_taper` | 0.0 | 始筆を軽く入れる | 実機は始筆かすれ得るため0推奨 |
| `connection_strength` | 0.0 | 同字の近い画を薄く続ける（連綿） | Z一定なので実機OK。近いほど高確率＋乱数 |

実機（単線シャーペン）は描画中に Z を上下させると点線化するため、筆圧変化・入筆は 0 が安全。
連綿は Z 一定なので実機でも使える。

### プリセット

| 用途 | messiness | temperature | instance_variation |
|---|---|---|---|
| **レポート提出（既定）** | 0.4 | 0.2 | 0.1 |
| きれいめ（丁寧に書いた） | 0.3 | 0.15 | 0.05 |
| 汚し（急いで書いた） | 0.8 | 0.35 | 0.3 |

`pressure_variation` `entry_taper` は実機では 0 のまま。`connection_strength` は雰囲気を出したいとき 0.3〜0.5。
