# 入力書式リファレンス

本文（Gradio UI / MCP）の書き方。Markdown 風の記法で手書き風に組版する。
MCP 版の要約は `src/mcp_server/server.py` の `_MCP_SYNTAX_HELP`（変更時は両方更新）。

## 見出し

`# 大` `## 中` `### 小`（3段階、階層で左インデントが深くなる。フォント 1.15/1.08/1.0 倍）。

## 段落

空行で区切る。自動折り返し（禁則処理あり）。`\noindent 本文` で先頭行の字下げなし。

## 改ページ

`---`（ハイフン3個以上のみの行）で強制改ページ。章ごとに入れると章別ページになる。

## 数式

| 種類 | 書き方 | 説明 |
|---|---|---|
| インライン | `$V = IR$` | 文中に埋め込む |
| ブロック | `$$E = mc^2 \tag{1}$$` | 独立行に中央配置。`\tag` で式番号、`\\` で複数段 |
| 分数 | `$\frac{a}{b}$` | **ブロック内の入れ子は `\dfrac`**（subsize 累積による縮小防止） |
| 平方根 | `$\sqrt{2gh}$` | 幾何描画。`\sqrt{\frac{a}{b}}` の入れ子OK |
| 上付き/下付き | `$x^2$` `$p_1$` `$x^{10}$` | 複数文字はブレース |
| ギリシャ | `\alpha \beta \Delta \sigma \rho \nu \lambda \pi \mu` | Unicode 直書き（Δ σ ν）も可 |
| 演算子 | `\cos \sin \tan \log \exp \sum \int \cdot` | LaTeX 記法 |

- 単純式（sub/sup/frac/sqrt なし）は本文と同じ手書き書体で描画（書体が浮かない）
- ブロック数式のトップレベル分数は分数線が用紙罫線に揃う（分子上の行・分母下の行）
- 長い式は自動縮小。`\\` で2段にした方が読みやすい
- 数式内 `.` は小数点のまま。本文の `.` は句点 `。` に自動変換

## 表（Markdown パイプ表）

```
| 材料 | 降伏応力 |
|---|---|
| SS400 | 245 |
: 表1 各材料の機械的性質
```

- 区切り行 `|---|---|` 必須（無いと本文扱い）
- 表の前後どちらかに `: タイトル` 行を書くとキャプション（省略可）。**学術慣例に従い表のタイトルは常に表の上に描く**（後置きしても上に配置）
- 本文幅中央配置、横罫線は用紙罫線に一致、幅超過は自動縮小

## 図（ブロック図・デンドログラム）

制御ブロック線図とデンドログラムをフェンスブロックで描ける。詳細・例・制約は [図リファレンス.md](図リファレンス.md) を参照。

**ブロック図**（制御系）:
````
```blockdiagram
R --> [制御器] --> [プラント] --> C
feedback: [センサ]
```
````
`[箱]` / `(Σ)`加算点 / 裸の文字=信号。`feedback:` 行でクローズドループ、無ければオープンループ。

**デンドログラム**（階層クラスタリング）:
````
```dendrogram
order: B C A D E
B + C : 1
A + D : 2
BC + AD : 3
ABCD + E : 4
```
````
`order:` で葉順、`X + Y : h` で結合（クラスタは構成文字の連結、順不同）。結合距離 h を高さにした U 字樹形図＋高さ軸。

## 使えない記法

画像 `![]()`、リンク、箇条書き `- `、太字/斜体、コードブロック（文字としてそのまま描かれるか無視）。

## settings（スライダー / MCP 引数）

| キー | 既定 | 効果 |
|---|---|---|
| `temperature` | 0.2 | 字形の揺らぎ（ML offset） |
| `messiness` | 0.4 | 行内上下動・字間・サイズ・傾き |
| `instance_variation` | 0.1 | 同じ字を毎回少し変える |
| `pressure_variation` | 0.0 | 画内の濃淡（実機は0: Z振動で点線化） |
| `entry_taper` | 0.0 | 始筆の入り（実機は0: かすれ） |
| `connection_strength` | 0.0 | 連綿。Z一定なので実機OK（0.3〜0.5目安） |

プリセット: **既定=レポート提出向け** / きれいめ `0.3/0.15/0.05` / 汚し `0.8/0.35/0.3`（messiness/temperature/instance_variation）。
