# 図リファレンス（ブロック図・デンドログラム）

本文 md にフェンスブロックを書くと、制御ブロック線図・階層クラスタリングのデンドログラムを手書き風ストロークで組版する。MCP（`render_preview`/`generate_gcode`）・Gradio UI どちらの入力でも使える。

実装: `src/layout/diagram_layout.py`（パース）＋ `src/layout/typesetter.py`（`_place_diagram`/`_place_dendrogram` 配置）。文章の書式全般は [書式リファレンス.md](書式リファレンス.md)。

---

## ブロック図（blockdiagram）

制御系のオープンループ／クローズドループ線図を描く。

### 記法

````
```blockdiagram
R --> [制御器] --> [プラント] --> C
feedback: [センサ]
```
````

- **開始行** ` ```blockdiagram `、**終了行** ` ``` `
- **メインチェーン行**: `-->` 区切りのノード列。ノードの種類:

| 書き方 | 種類 | 描画 |
|---|---|---|
| `[ラベル]` | 箱 | 矩形＋中央にラベル文字 |
| `(ラベル)` | 円形ノード | 円＋中にラベル |
| `(Σ)` `(+)` `(sum)` | 加算点 | 円＋Σ。大文字小文字問わず |
| 裸の文字（`R` `C` `Y`） | 信号ラベル | 箱なし、文字だけ |

- **`feedback:` 行**（任意）: あるとクローズドループ。`feedback: [センサ]` の箱を帰還経路に置く。最初の信号の直後に加算点 Σ が自動挿入され、出力から下を回り込んで Σ の下入力（−）へ戻る（左入力＝R の＋）。`feedback:` 行が無ければオープンループ（一直線）。

### 例

**オープンループ**
````
```blockdiagram
R --> [制御器] --> [プラント] --> C
```
````

**クローズドループ**（フィードバック制御）
````
```blockdiagram
R --> [制御器] --> [プラント] --> C
feedback: [センサ]
```
````

**加算点を明示**（外乱の合流など）
````
```blockdiagram
R --> (Σ) --> [制御器] --> [プラント] --> C
feedback: [センサ]
```
````

### 制約（v1）

- 帰還経路は水平1行帯のみ（縦に迂回する多段帰還は非対応）
- 円は16角形近似（真円ではないが手書き風なので実用上問題なし）
- 図キャプション（`: タイトル`）は未対応
- 図が本文幅を超える場合は全体を自動縮小

## デンドログラム（dendrogram）

階層的クラスタリングの結果を、結合距離を高さとした樹形図で描く。

### 記法

````
```dendrogram
order: B C A D E
B + C : 1
A + D : 2
BC + AD : 3
ABCD + E : 4
```
````

- **開始行** ` ```dendrogram `、**終了行** ` ``` `
- **`order:` 行**: 葉を左から並べる順序。空白区切り。この順に等間隔で x 軸へ配置
- **結合行** `X + Y : h`: クラスタ X と Y を高さ h で結合
  - クラスタは**構成要素の文字を連結**して表す。`BC` は葉 B と C の併合クラスタ、`ABCD` は A,B,C,D の併合
  - 順不同（集合として扱う。`BC` と `CB` は同じ）
  - 高さ h は整数・小数どちらも可
- 各結合は U 字ブラケット（2つの子の x 位置から高さ h まで垂直線を立ち上げ上端を水平線で結ぶ）。結合後クラスタの x は2子の中点。左側に高さ軸と目盛り数値。

### 葉の順序の決め方（重要）

`order:` は**結合が必ず隣り合うクラスタ同士になる**よう並べる。交差のない樹形図にするための前提。

例のデータ（A=5, B=1, C=2, D=7, E=11、最短距離法）の結合順は BC→AD→(BC+AD)→(+E)。これらが隣接するには `order: B C A D E` とする（B,C が隣、A,D が隣、その2ブロックが隣、最後に E）。値の昇順（B C A D E）に並べれば自然にそうなることが多い。

### 例（最短距離法・単連結）

上記の記法例がそのまま完全な例。レンダすると:
- 葉 B C A D E が下端に等間隔
- B-C が高さ1、A-D が高さ2、{B,C}と{A,D}が高さ3、E が高さ4で全体合流
- 左に高さ軸（目盛り 0,1,2,3,4）

### 制約（v1）

- 葉ラベルは1文字想定（複数文字も動くが幅の重なり回避は未検証）
- 高さ目盛りは昇順描画。通常のデンドログラム（単調増加）を前提
- 図キャプション未対応
- 本文幅超過時は葉間隔を自動縮小、狭ければ本文幅の中央へ寄せる

## 図番号・キャプション

DSL 自体はキャプション未対応。図番号を付けるときは本文で参照し、図の近くに手書きの本文行として書く:

```
オープンループ制御の系を図1に示す。

​```blockdiagram
R --> [制御器] --> [プラント] --> C
​```

図1 オープンループ制御系
```

（`図1 …` は通常の本文行として中央寄せされずに描かれる。中央に置きたい場合は前後に空白を入れて調整する。将来的にキャプション対応を追加予定。）
